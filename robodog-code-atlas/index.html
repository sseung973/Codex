01 / CONNECT
USB 동글 연결
동글을 컴퓨터에 꽂고 로보독 전원을 켜. Windows 장치 관리자에서 Dongle(COM...) 포트 확인. 여러 대를 연결할 땐 하나씩 페어링해.
02 / INSTALL
Python 라이브러리 설치
Thonny나 PC Python 환경에서 설치 명령을 실행해. 공식 패키지 페이지 ↗
python -m pip install kocoafab-robodog
03 / RUN FIRST
첫 LED 테스트
LED 출력부터 테스트해. 보행·회전보다 안전하게 연결 여부를 확인할 수 있어.
04 / EXTEND
AI · 멀티 로보독
카메라 인식과 다중 로봇 제어 API까지 소스에 구현돼 있어. 다만 모든 모델에 해당 하드웨어·펌웨어가 있는지는 개별 확인이 필요해.

📎 소스 및 주의사항
이 문서는 사용자 제공 robodog.py, deflib.py, __init__.py 및 「로보독 기초 가이드 교안(파이썬)」을 기준으로 작성했어. 내부 전송 함수와 별칭까지 모두 나열했으므로 카테고리 내부·고급은 일반 제어용이 아니야. 각 소스 기반 카드에는 실제 파일의 함수 시작 줄 번호를 표시해. 모터는 낮은 속도·작은 각도부터, 움직임은 넓고 평평한 바닥에서, 종료 시 STOP과 Close를 사용해.
