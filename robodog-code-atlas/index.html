연결부터 실행까지
처음 로보독 빅아이를 실행하는 사람을 위한 간단 가이드
1
USB 동글과 로보독 페어링
동글을 PC에 꽂고 로보독 전원을 켜. Windows 장치 관리자에서 Dongle(COM...) 포트를 확인해. 연결이 안 되면 교안 27~31쪽을 확인해.
2
Python 설치 및 라이브러리 준비
교안은 Thonny를 소개하고, 공식 PyPI 패키지는 Python 3.8 이상을 요구해. Thonny나 PC Python 터미널을 이용해.
python -m pip install kocoafab-robodog
3
첫 LED 제어 실행
로봇을 평평한 바닥에 놓고 아래 코드를 실행해. 연결/LED 호출이 정상인지 먼저 확인하자.
4
확장 프로젝트 선택
AI 손동작·얼굴·물체 인식은 로보독의 신규 공식 명령어가 아니라 PC 카메라/마이크를 Python 앱에 연결하는 별도 프로젝트야.
주의할 점
다리를 손으로 강제로 움직이지 말고, 책상 끝이나 높은 곳에서 보행을 시험하지 마. 연결이 끊기거나 배터리가 부족하면 동작이 약해질 수 있어. 장시간 무한 반복보다 종료 조건이 있는 짧은 데모를 추천해.
