# SHUTTLE RUSH · 친구 대전

플레이: https://shuttle-rush-online-sseung973.onrender.com

기존 웹 배드민턴의 AI 단식·연습·타구 비교·대회와 일러스트 타이틀을 유지하며, 방 코드 기반 온라인 단식(2명)과 복식(4명)을 제공합니다.

`npm ci` → `npm start`로 실행합니다. `PORT` 환경변수(기본 10000)와 0.0.0.0 바인딩을 사용합니다. 정적 화면과 WebSocket /ws를 같은 Node 프로세스가 제공하며 `/healthz`는 상태 확인용입니다.

타이틀 → 시작하기 → 친구 대전에서 선수/이름과 1대1 또는 2대2를 선택하고 방을 만드세요. 친구는 6자리 코드 또는 초대 링크로 참가합니다. 전원이 준비 완료를 누르면 방장이 시작합니다. 복식은 실제 접속한 네 명이 A/B 두 팀으로 플레이합니다. 팀당 두 자리이고 빈 자리가 있을 때 팀을 변경할 수 있습니다.

자동 이동을 보조하며 마우스/터치 스와이프 또는 Space로 타격합니다. Q/W/E/R과 1–4로 클리어/드롭/드라이브/스매시를 고릅니다. 드롭은 낮은 공도 네트 앞에 짧게 돌려줄 수 있으며, 앞코트에서 치면 낮고 빠르게 떨어집니다. 스매시는 높은 공에서만 가능하고, 불가능한 입력에는 이유가 표시됩니다. 온라인 스윙의 전송·타격 대기를 구분하며 실제 임팩트 때 타격 효과가 납니다. 선수별 능력과 체력은 서버에서 적용합니다. 대각선 서브, 복식의 넓은 코트와 짧은 서브 후방선, 11점 2점 차·15점 상한을 판정합니다. 받은 팀의 한 명만 한 번 타격할 수 있습니다.

친구 대전은 방을 만들 때 **3판 2선승** 또는 **한 세트**를 고릅니다. 세트마다 11점(2점 차, 15점 상한)이며 3판 2선승은 두 세트를 먼저 이기면 종료됩니다. 세트 사이 8초 휴식 뒤 다음 세트가 자동 시작되고, 세트 점수와 각 세트 결과는 경기 화면/종료 화면에 표시됩니다. 휴식도 일시정지할 수 있습니다.

복식 방의 **우리 팀 포메이션**에서 앞뒤 공격형 / 좌우 수비형을 고르고 두 선수의 역할을 맞바꿀 수 있습니다. 바꾸면 우리 팀만 준비 완료를 다시 눌러야 합니다. 경기 중에는 경기 설정 → 친구 대전에서 서브 준비·포인트/세트 휴식·일시정지 때 바꿉니다. 각자 맡은 위치로 자동 복귀하며, 실제로 닿을 수 있는 팀원의 스윙 입력이 우선합니다.

서버가 120Hz로 물리·타격·득점을 계산하고 30Hz로 상태를 전달합니다. 클라이언트는 각자 자기 코트 쪽에서 보는 화면으로 변환하며 두 상태 사이를 보간합니다. 각 선수는 자기 입력만 전송하고 공의 위치나 점수를 설정할 수 없습니다. 타격은 기존 physics.js의 궤적 해석기를 재사용합니다.

연결이 끊기면 모두 일시정지하고 자리를 90초간 유지합니다. 같은 탭에서 새로고침/재접속하면 sessionStorage의 비공개 토큰으로 복구하며 카운트다운 후 재개합니다. 다른 탭/기기로 토큰을 전달하지 않습니다. 방 나가기 또는 복귀 시간 초과는 팀 기권입니다. 방장이 종료 후 다음 경기 준비를 누르면 같은 방을 다시 사용할 수 있습니다.

Render 무료 Node Web Service 한 인스턴스를 사용합니다. 무료 서비스는 유휴 후 첫 접속이 느릴 수 있습니다. 방은 메모리에 있어 서버 재배포/재시작 시 사라집니다. 다중 인스턴스는 공유 방 저장소/라우팅을 추가하기 전 사용하지 않습니다. 별도 데이터베이스·사용자 계정·외부 메시지 전송이 없습니다. 기존 Sites의 소스/공개 설정은 변경하지 않습니다.

검사: `npm test`(서버 물리·방·실제 HTTP/WebSocket), `node tests/online-browser.cjs`(2/4개 독립 브라우저의 실제 입력, 점수 동기화, 새로고침 복귀, 기권/재경기), `node tests/online-return-browser.cjs`(서브 → 상대 리턴 → 원래 서버의 재타격, 폰/패드 스와이프와 손을 계속 누른 입력, PC 키, 낮은 스매시 안내, 4인 복식), `node tests/competition-browser.cjs`(경기 길이 선택, 포메이션/역할 공유와 준비 상태, 세트 전환·2:1 종료·대기방 복귀), 기존 `tests/*.test.cjs`와 브라우저 회귀 검사. 로컬 세트 UI 검사는 신뢰된 테스트 서버에서 착지를 가속해 점수를 진행하고, `LIVE_ORIGIN`에서는 실제 브라우저 서브/리턴으로 세 세트를 끝까지 플레이합니다. 브라우저 검사는 작업환경에 이미 설치된 Chromium/Playwright를 사용하며, 실물 iOS/Safari 검사는 별도입니다. `LIVE_ORIGIN`을 실제 Render URL로 지정하면 동일한 온라인 검사를 배포 주소에서 실행합니다.

타이틀 일러스트는 이 게임을 위해 생성한 자산입니다. 폰트와 OFL 라이선스는 dist/assets에 있습니다. 디자인 결정은 DESIGN.md에 기록합니다.
