# 2026-10-22 Unity 수정 패키지

기존 `relay-zero-unity` 프로젝트를 이미 실행했다면 전체 저장소를 다시 받을 필요가 없습니다.

1. [수정 패키지 다운로드](https://github.com/sseung973/Codex/raw/refs/heads/main/relay-zero-unity/Updates/RelayZero-Fixes.unitypackage).
2. Unity에서 **Play를 정지**합니다. 기존 작업을 저장하고 프로젝트 폴더의 사본을 보관하세요.
3. **Assets → Import Package → Custom Package…**에서 받은 파일을 선택하고 **Import**를 누릅니다. 이 패키지는 `Assets/RelayZero` 아래 C#·셰이더 파일만 갱신합니다. 프로젝트 설정, 개인 에셋, 기존 폰트·맵 데이터를 교체하지 않습니다.
4. 컴파일이 끝나면 **RELAY ZERO → Run Play Mode Smoke Check**를 실행합니다. 완료 시 Console에 `RELAY ZERO Unity Play Mode smoke passed`가 표시됩니다. 실패하면 첫 빨간 오류와 스택을 보내주세요.
5. 이어서 Play로 실제 메뉴·전투·설정 화면을 확인합니다. 자동 검사 통과는 전체 화면과 플레이를 사람이 확인했다는 뜻이 아닙니다.

## 수정 범위

- 한글 제목·알림에 영문 전용 폰트를 적용하던 문제. 실제 글리프 지원 여부로 폰트를 고르고, 동적 문구가 바뀔 때도 다시 선택합니다. 제공 폰트에 없는 처치 기호를 교체했습니다.
- 글꼴의 줄 높이보다 작은 텍스트 상자가 글자를 잘라내던 문제와 두 줄 게임 제목의 크기.
- 설정 슬라이더의 채움 막대가 부모 폭·높이보다 커지고 손잡이 기준점이 맞지 않던 문제.
- 맵 표지판의 폭·높이에 맞는 크기 조절, 전용 깊이 검사 셰이더, 폰트 아틀라스 갱신 대응.
- 메뉴 시작·재개 클릭의 사격 전달 차단. 주무기를 상점에서 교체할 때 이전 무기의 재장전과 공격 상태 초기화.
- 넥서스 연습장 표적이 엄폐물과 겹치는 고정 좌표 대신 빈 탐색 격자를 사용.
- 지휘 로봇의 경고 원을 월드에 고정. 지휘 로봇이 지원형·저격형 등 일반 적의 역할 설정을 물려받지 않도록 분리.
- 경사 구간에서 AI가 높이 차이 때문에 다음 경유 지점으로 넘어가지 못하는 문제와 정지·기절 중 중력 처리.
- 저격 조준경과 일반 크로스헤어의 중복 표시. 새 판에 남던 명중·피격·탄도 효과 초기화.
- 온라인 방을 떠난 뒤 남는 역할·준비·명단 초기화, 서버 ping 응답이 친구의 무응답을 가리던 타이머, 사라진 적과 방패 장식의 동기화.
- 오랫동안 회전한 플레이어의 전송 각도가 서버 제한을 넘지 않도록 정규화.
- 가져온 프리팹의 크기 맞춤이 카메라·로봇의 월드 회전에 영향받던 문제.
- 반복 실행 시 생성한 UI 스프라이트·재질·효과음의 정리.

## 검증 범위

이 환경에서 런타임 C# 컴파일, 독립 규칙 검사, 메시·폰트·아이콘 정적 검사를 수행했습니다. Unity Editor와 사용자 PC의 화면을 원격으로 실행·검사한 것은 아닙니다. 위 Play Mode 검사에는 실제 엔진에서 수행할 폰트·슬라이더·표적 배치·표지판·방패·보스 경고·약점·재장전·온라인 상태 직렬화·프리팹 회전 검사가 포함되어 있습니다.

패키지는 이 저장소의 원본 C#·셰이더로만 생성되며 Asset Store 콘텐츠를 포함하지 않습니다. 재생성: `python Tools/make-code-update.py`.
